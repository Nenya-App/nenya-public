## Usage Notes

### Primary Colors (First in Each Vector)
The first color in each vector is the "gravity well" or primary diagnostic color. This is the most representative color for each Valar and should be used when:
- Creating single-color representations
- Displaying Valar icons or symbols
- Showing primary identity in UI elements
- The orbiting Valar orbs on the landing page

### Gradient Construction
For gradient displays (like in the Pantheon of Needs page), use:
- **Core Color:** First color in vector (Primary/Gravity Well)
- **Accent Color:** Third, fourth, or fifth color (contextual)
- **Shadow Color:** Last color in vector (deepest/darkest)

### Consistency Across Components
All three locations MUST use these exact colors:
1. **ValarColorPicker** (`/components/ValarColorPicker.tsx`) - Visual Gateway palettes ✓
2. **ValarBreathingLogo** (`/components/ValarBreathingLogo.tsx`) - Orbiting orbs ✓
3. **PantheonOfNeeds-fixed** (`/components/about/PantheonOfNeeds-fixed.tsx`) - Description boxes ✓

### Color Theory
- Manwë & Varda share sky/celestial themes (blues, silver, purple)
- Ulmo & Nienna share water/emotion themes (blues, lavenders, soft pastels)
- Aulë & Yavanna share earth themes (browns, greens, copper)
- Oromë, Tulkas, Nessa share vitality themes (golds, oranges, vibrant tones)
- Irmo & Estë share dream/rest themes (pale blues, greys, soft whites)
- Melkor uses shadow themes (dark reds, maroon)
- Morgoth (Fallen) uses void themes (near-black, deep indigo, dark violet - Ungoliant palette)
