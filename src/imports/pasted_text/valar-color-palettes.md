## Usage Notes for Figma AI Designer

- Use the **Gravity Well (color 1)** as the primary diagnostic accent – for card borders, active filter states, dot gravity wells.
- Build gradients from color 1 to color 6 for backgrounds, hover states, or modal overlays.
- For strategy dots with multiple Valar tags, blend the Gravity Well colors using a split‑circle or gradient pattern.
- Ensure sufficient contrast when placing text over these colors (light mode recommended; dark mode would require inversion).
- These palettes replace the previous arbitrary assignment and are grounded in traditional color theory (air = blue, water = blue/teal, earth = green/brown, fire/joy = orange/red, grief = grey, etc.).
