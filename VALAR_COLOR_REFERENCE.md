## Usage Notes

### Primary Colors (First in Each Vector)
The first color in each vector is the "gravity well" or primary diagnostic color. This is the most representative color for each Valar and should be used when:
- Creating single-color representations
- Displaying Valar icons or symbols
- Showing primary identity in UI elements
- The orbiting Valar orbs on the landing page

### Gradient Construction
For gradient displays (like in the Pantheon of Needs page), use:
- **Core Color:** First color in vector (Primary/Gravity Well)
- **Accent Color:** Third or fourth color (contextual)
- **Shadow Color:** Fifth or sixth color (lightest/palest)

### Consistency Across Components
All three locations MUST use these exact colors:
1. **ValarBreathingLogo** (`/src/app/components/ValarBreathingLogo.tsx`) - Breathing emanations ✓
2. **ValarColorPicker** (`/src/app/components/ValarColorPicker.tsx`) - Visual Gateway palettes ✓
3. **NenyaLogo** (`/src/app/components/NenyaLogo.tsx`) - Orbiting orbs ✓
4. **PantheonOfNeeds-fixed** (`/src/app/components/about/PantheonOfNeeds-fixed.tsx`) - Description boxes ✓

### Color Theory
- Manwë & Varda share sky/celestial themes (blues, creams, ethereal tones)
- Ulmo & Nienna share water/emotion themes (blues, greys, soft pastels)
- Aulë & Yavanna share earth themes (terracotta, greens, natural tones)
- Oromë, Tulkas, Nessa share vitality themes (olives, oranges, corals, vibrant tones)
- Irmo & Estë share dream/rest themes (purples, teals, soft calm tones)
- Melkor & Ungoliant share shadow themes (dark browns, blacks, muted purples)
