How to read this

The tapestry lives inside Pattern’s “More descriptions”. It is optional, and Pattern can be added to the report without it. Each card is a real page of controls on the left (try the keyboard) and its notes on the right. Every card has Emergency Exit first in the tab order. Nothing here sends anything, makes a sound or saves.

Choosing fewer can be more helpful than choosing many. A tapestry has a base and up to three layers above it; a fourth layer gets a warning, never a block.

    Tab order

    1. Emergency Exit
    2. Put this down
    3. Base pattern, Add a layer (list, then button)
    4. Each layer’s Remove button
    5. Take off the top layer, Start again
    6. Skip, Next

    A screen reader says

    • The picture is a named image. The line under it says the same thing in words every time something changes: “base: layered, then branching, then circular”. It never moves focus.
    • At a fourth layer the notice is announced once and focus moves to “Add it anyway”. “Keep three” returns focus to the Add button.

    Responds live (try it)

    • Each layer is drawn on top of the one before it. Under reduced motion layers appear at once, with no fade.
    • Every control is a plain list or button. Nothing needs a pointer.
