The Sight lens: four cards

All wireframes · Sound · Draft 2026-11-17 · plan: docs/lens-audit-sight-sound.md

How to read these

Each card is a real page of controls on the left (try the keyboard: Tab, Space, arrow keys) and its notes on the right: the tab order, what a screen reader says, what responds live, and the copy draft. Every card has Emergency Exit first in the tab order. Nothing here sends anything anywhere.

The lens is picked up from the tray in any order. Cards run in order inside the lens. Nothing is in the report until the last card's Add this to my report.

A screen reader says

  • Heading level 2, “Pick two colors”. Each swatch is a named image: “Your color for now: a steel blue”.
  • The slider: “How strong is it? Faint to strong. Medium.” The status line is polite and says the word each time it changes; it never moves focus.
  • “Skip this” sets the slider to unset: choosing nothing is a choice.

Responds live

  • The strength slider changes the swatch (saturation and the size of its glow) and the word beside it. Try it.
  • Reduced motion: the change is instant, no easing.

Choose the color

Opens the picker as a dialog: the sixteen palettes as starting points, then the colors in each (named). Focus moves in, Esc closes and returns focus to the button, “Use this color” confirms. Not drawn here.

Copy draft (about grade 5)

“Pick two colors. One for how you feel now. One for how you wish to feel.” The old “Everything is optional” card is folded in: names and strength are marked optional where they appear.

This sends one color, as a hex code, through our server to The Color API. Nothing else goes. See the Terms.

Your palettes (choose any to keep)

Marked palettes can also be heard in Sound.

Tab order

  1. Emergency Exit
  2. Put this down
  3. Make a palette here
  4. The outside-service disclosure, then its button
  5. The palettes (checkboxes)
  6. Skip, Next

A screen reader says

  • Each palette lists its colors by name, never only as swatches.
  • The outside-service button is inside a disclosure that states exactly what is sent before it can be pressed.

Copy draft

“A palette is a starting point, not a measurement.” (The site already says this; the line stays.)

Notes

  • Making a palette on the device sends nothing.
  • The outside request is a separate press each time and works only if the person asks.

Sight · card 4 of 4

Add Sight to your report?

This is what would be added:

  • Now: steel blue, medium strength
  • Wish: warm amber, medium strength
  • Palettes: none
  • Body: none marked

Added. You can come back and change it.

If put down without adding

Your report will say: “Examined, not included: Sight.” Anything you chose on this lens stays here, marked “not in your report yet”, until you leave. It is never saved unless you add it.

Tab order

  1. Emergency Exit
  2. Put this down (top)
  3. The summary (read as a list)
  4. Add this to my report
  5. Put this down

A screen reader says

  • The summary is a real list. After pressing Add, focus moves to “Added.” and it is read once.

States

  • Before: as drawn.
  • Added: the same card reopens with Update and Remove.
  • Examined: the one report line above, kept on the device only.

Playful, within the limits

A still “added” state and, if motion is allowed, one soft glow on the swatches. No points, streaks or badges.
