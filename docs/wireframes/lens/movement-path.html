The path of movement: an optional activity

All wireframes · Movement · Tapestry · Draft 2026-11-18 · plan: docs/lens-audit-movement-pattern.md section 4

How to read this

The path lives inside Movement’s “More descriptions”. It is optional, and Movement can be added to the report without it. Each card is a real page of controls on the left (try the keyboard) and its notes on the right. Every card has Emergency Exit first in the tab order. Nothing here sends anything, makes a sound or saves.

You can draw the path with a pointer or finger, or build it with the step buttons. Both make the same path and the same words.

  5. Watch it move, Undo, Clear
  6. Skip, Next

A screen reader says

  • The pad is a named image and is not a tab stop; the step buttons are the full alternative. The line under it says the path in words after every change: “starts at the left, goes right, then up, then right; gently”. It never moves focus.

Responds live (try it)

  • “Watch it move” sends a dot along the line. Under reduced motion the dot is not animated: the whole line shows, with a dot at the end.
  • The feel word sets the look of the line (broken for jerky or hesitant, thick for forceful, thin for gentle) and is repeated in words.

Not drawn here

If skipped

Movement is added exactly as it would be without a path. Nothing is lost and nothing is asked again.

States

  • Before: as drawn.
  • Kept: Movement reopens with the path as you left it.
  • Skipped: no path words in the report.

Playful, within the limits

No points, streaks or badges. A path is never graded.
