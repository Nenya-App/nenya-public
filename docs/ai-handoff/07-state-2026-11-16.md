## What runs tonight, in plain words
Workers AI's free daily allowance (10,000 Neurons) resets at 00:00 UTC, which is 6 pm Central. Unspent Neurons are lost, so on staging a scheduled function wakes every minute from 23:00 to 23:59 UTC (5:00 to 5:59 pm Central) and plays invented persona conversations through the real coach, spending only what is genuinely unused that day, never more than 3,000. Tonight's alternate task is **instructions v2** (compared with v2.1, the baseline, which runs twice after it). It saves its place after every case, and at the end (or by minute 55) writes a digest to the staging store at `canary/digest-2026-11-16`: pass counts, median reply length and reading grade, drift flags, failed case ids, never any text. Nothing visitors write is involved. Rotation after that: Learn stance, v2, candidate model, repeating. The daily deletion jobs also run on their own schedules (08:00 UTC for coach cleanup).
**How it helps:** repeats show which cases are shaky (a single run proves little); drift flags catch a model quietly changing; the alternates compare instructions and models on the same cases for free; reading grades track the plain-language goal; and every failure found becomes a fixed test.
